# Developer Platform & API Key Scopes

## 1. API Key Authorization
Enterprise organizations can generate scoped REST API keys prefixed with `mae_live_`.

## 2. Supported Scopes
- `exam:read`: Query exam catalog and details.
- `exam:write`: Create or update exam questions and hidden test cases.
- `submission:read`: Query candidate submission facts and final evaluation reports.
- `analytics:read`: Retrieve organization performance intelligence.
