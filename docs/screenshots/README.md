## Capture Guidelines & Privacy Rules

1. **Resolution**: Capture at $1920 \times 1080$ minimum resolution in light/dark theme.
2. **Redaction**: Mask real JWT bearer tokens, database connection strings, and API keys.
3. **Format**: Save as 24-bit PNG files named according to the table index above (`01-login.png` through `13-security-class-isolation.png`).
