# Enterprise Identity Architecture (OIDC, SAML, SCIM)

## 1. Authentication Integration
- **OAuth2 / OIDC**: Supports federated authentication via enterprise identity providers (Okta, Azure AD, Ping Identity).
- **SAML 2.0**: Service Provider (SP) assertion parsing and attribute mapping.
- **SCIM 2.0**: User provisioning and automated account deactivation endpoint (`/scim/v2/Users`).
