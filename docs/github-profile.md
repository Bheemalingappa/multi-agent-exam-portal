## 4. Pinned Project Descriptions

### Short (1 Sentence)

### Medium (2–3 Sentences)
> EduExam is a cloud-native assessment platform designed for K-12 institutions. It leverages Google Gemini for structured, multi-lingual question synthesis and a multi-agent consensus pipeline for automated answer evaluation. Deployed on AWS EKS with PostgreSQL and Redis, it features robust class-level security and real-time analytics.

### Technical (4–5 Sentences)
> Built on AWS EKS, EduExam combines FastAPI microservices and a React+TypeScript frontend to deliver a secure digital examination environment. The platform integrates Google Gemini (`google-genai` SDK) for multi-lingual (`English` & `Kannada`) question generation across three source material modes (`TOPIC_ONLY`, `PDF_ONLY`, `PDF_AND_TOPIC`). Student submissions undergo hybrid automated grading—exact match for MCQs, rubric-guided partial credit for short answers, and multi-agent consensus for long descriptive responses. Enterprise controls include role-based JWT authentication, class-level authorization, server-authoritative timers, and real-time analytics.
