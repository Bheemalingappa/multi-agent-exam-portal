# Naukri Profile Project Entry

### Project Name: Multi-Agent Exam & Evaluation Portal (EduExam)
**Role**: Full-Stack AI & Cloud Engineer  
**Project Type**: AI & Cloud Infrastructure Assessment Platform  

### Description:
- Engineered a cloud-native K-12 examination platform on **AWS EKS** using **FastAPI**, **React**, **TypeScript**, **PostgreSQL**, and **Redis**.
- Integrated **Google Gemini API** for multi-lingual (`English` & `Kannada`) AI question paper generation across topic-based and PDF source material modes.
- Built a **Multi-Agent Evaluation Pipeline** delivering automated MCQ grading, rubric-guided short-answer partial scoring, and long-answer multi-agent consensus evaluation.
- Implemented role-based JWT authentication, class-level exam isolation (Classes 1–12), server-authoritative timers, and IDOR security controls.
- Developed real-time student performance dashboards and teacher analytics featuring itemized question difficulty metrics and sortable class rosters.

**Technologies**: Python, FastAPI, React.js, TypeScript, Google Gemini API, PostgreSQL, Redis, Docker, Kubernetes, AWS EKS, Tailwind CSS.
